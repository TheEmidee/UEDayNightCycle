# UE Day & Night Cycle

This plugin provides a basic framework to handle a day & night cycle system in Unreal Engine

## How to use

You first need to create a data asset of type `DNCDayDefinition` in your project. 

This asset will allow you to define:
* How long (in real time) a day will last in the game
* At what time the day starts when you start a new cycle
* Periods of time
* Observers

You then need to start a new cycle by calling the function `StartCycle` on the `DNCWorldSubsystem`.

## Periods of time

You define a period by creating an asset of type `UDNCPeriod`, and you register a period through the day definition asset.

A period is defined by a `StartTime` and a `TimeSpeedDilation`. When a period starts, it will end the previous period. The `TimeSpeedDilation` property is a multiplier of the speed at which time moves on in the system (and that is computed when the cycle starts, based on the virtual day duration). This allows for example to have nights move faster in time compared to days.

## Observers

You define an observer by creating an asset of type `UDNCObserver`, and you register observers through the day definition asset.

Observers allow you to run any code based on some events generated by the system:
* When the cycle starts
* When the current time of the day changes
* When a period starts, or ends

The functions are all `BlueprintImplementableEvent` to allow you to define your own logic in blueprint.

A usage could be for example to update the sun position in the sky each frame based on the current time, or to switch some lamps on in your world when the night period starts.
